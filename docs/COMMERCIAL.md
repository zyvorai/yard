# Commercial boundary

`GET /api/v1/meta` reports an `edition` field (currently the API value `community`). `GET /api/v1/compliance/export` is the admin CSV of that edition, the users, and the audit log.

There is no billing and no license server in this tree. Non-production use is free; a commercial license from Zyvor is required for production use (sales@zyvor.dev).

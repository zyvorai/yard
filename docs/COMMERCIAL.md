# Commercial boundary

`GET /api/v1/meta` reports an `edition` field (currently the API value `community`). `GET /api/v1/compliance/export` is the admin CSV of that edition, the users, and the audit log.

There is no billing and no license server in this tree. A 30-day trial is available on request from sales@zyvor.dev (a paid evaluation Order at no charge); production and any other use needs a paid Order under the Zyvor Production Licence v2.0.
